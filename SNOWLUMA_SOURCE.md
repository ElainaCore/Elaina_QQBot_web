# SnowLuma WebUI source notice

This WebUI was rebuilt from the visual and component structure of SnowLuma WebUI,
then adapted to ElainaBot's authentication, runtime, process, account, log, and
system APIs.

- Upstream project: https://github.com/SnowLuma/SnowLuma
- Upstream package: packages/webui
- Adapted product: ElainaBot QQ official robot framework

The ElainaBot backend and this adapted frontend remain separate from the
SnowLuma backend. Refer to the upstream repository for its current license,
EULA, privacy terms, and source history.
